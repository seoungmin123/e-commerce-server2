## 1. 상세 설계

### 1.1 시스템 아키텍처

#### 개선된 구조
```
사용자 요청 → Service → Redis 빠른 검증 → Event Publisher → Kafka → Consumer → DB 원자적 처리
            ↓                                                          ↓
        즉시 요청ID 반환                                            상태 업데이트
            ↓                                                          ↓
        폴링으로 상태 확인 ← ← ← ← ← ← ← ← ← ← ← ← ← ← ← ← ← ← ← ← Redis 상태 조회
```

#### 핵심 역할 분담
- **DB**: 실제 비즈니스 로직과 정합성 보장 (Source of Truth)
- **Redis**: 빠른 조회와 사용자 경험 개선 (Cache Layer)
- **Kafka**: 안정적인 메시지 전달과 비동기 처리

## 2. 구현 설계

### 2.1 요청 접수 단계 (Redis 활용)
```java
@Service
@RequiredArgsConstructor
public class CouponRequestService {
    private final RedisTemplate<String, String> redisTemplate;
    private final CouponEventPublisher eventPublisher;
    private final ObjectMapper objectMapper;
    
    @Transactional
    public String requestCoupon(Long userId, Long couponId) {
        String requestId = UUID.randomUUID().toString();
        
        // 1. Redis에서 빠른 사전 검증
        if (!canRequest(userId, couponId)) {
            throw new ApiException(ALREADY_ISSUED_OR_EXHAUSTED);
        }
        
        // 2. 요청 상태를 Redis에 저장 (폴링용)
        setUserStatus(userId, couponId, "PENDING", requestId);
        
        // 3. Kafka 이벤트 발행
        eventPublisher.publishEvent(
            CouponEvent.Requested.of(requestId, couponId, userId)
        );
        
        return requestId;
    }
    
    private boolean canRequest(Long userId, Long couponId) {
        // 이미 발급받았는지 Redis에서 빠른 확인
        String issuedKey = "coupon:" + couponId + ":issued";
        if (Boolean.TRUE.equals(redisTemplate.opsForSet().isMember(issuedKey, userId.toString()))) {
            return false;
        }
        
        // 쿠폰이 모두 소진되었는지 확인 (추정치)
        String countKey = "coupon:" + couponId + ":count";
        String maxCountStr = redisTemplate.opsForValue().get("coupon:" + couponId + ":max");
        String currentCountStr = redisTemplate.opsForValue().get(countKey);
        
        if (maxCountStr != null && currentCountStr != null) {
            int maxCount = Integer.parseInt(maxCountStr);
            int currentCount = Integer.parseInt(currentCountStr);
            if (currentCount >= maxCount) {
                return false; // 추정상 소진됨
            }
        }
        
        return true;
    }
    
    private void setUserStatus(Long userId, Long couponId, String status, String requestId) {
        String statusKey = "user:" + userId + ":coupon:" + couponId + ":status";
        
        // JSON 형태로 상세 정보 저장
        Map<String, Object> statusInfo = Map.of(
            "status", status,
            "requestId", requestId,
            "timestamp", System.currentTimeMillis()
        );
        
        try {
            String statusJson = objectMapper.writeValueAsString(statusInfo);
            redisTemplate.opsForValue().set(statusKey, statusJson, Duration.ofMinutes(10));
        } catch (JsonProcessingException e) {
            log.error("Failed to set user status", e);
        }
    }
}
```

### 2.2 실제 처리 단계 (DB 원자적 연산)
```java
@Component
@RequiredArgsConstructor
public class CouponIssueProcessor {
    private final DatabaseConcurrencyManager dbManager;
    private final CouponCacheManager cacheManager;
    
    @Transactional
    public void processIssueRequest(CouponEvent.Requested event) {
        try {
            // DB에서 원자적 쿠폰 발급 처리
            CouponIssueResult result = dbManager.tryIssueCoupon(event.couponId(), event.userId());
            
            if (result.isSuccess()) {
                // 성공 시 Redis 캐시 업데이트
                cacheManager.markAsIssued(event.couponId(), event.userId());
                cacheManager.incrementIssuedCount(event.couponId());
                cacheManager.updateUserStatus(event.userId(), event.couponId(), "SUCCESS", result.getCouponIssue());
                
            } else {
                // 실패 시 상태 업데이트
                cacheManager.updateUserStatus(event.userId(), event.couponId(), "FAILED", result.getFailureReason());
            }
            
        } catch (Exception e) {
            log.error("Failed to process coupon issue", e);
            cacheManager.updateUserStatus(event.userId(), event.couponId(), "ERROR", e.getMessage());
        }
    }
}

@Component
@RequiredArgsConstructor
public class DatabaseConcurrencyManager {
    private final CouponRepository couponRepository;
    private final CouponIssueRepository couponIssueRepository;
    private final UserRepository userRepository;
    
    @Transactional
    public CouponIssueResult tryIssueCoupon(Long couponId, Long userId) {
        try {
            // 1. 원자적 수량 증가 (DB 레벨에서 동시성 처리)
            int updated = couponRepository.incrementIssuedQuantityIfAvailable(couponId);
            if (updated == 0) {
                return CouponIssueResult.failed("쿠폰이 모두 소진되었습니다.");
            }
            
            // 2. 쿠폰 발급 기록 생성 (유니크 제약으로 중복 방지)
            Coupon coupon = couponRepository.findById(couponId)
                .orElseThrow(() -> new ApiException(NOT_FOUND));
            User user = userRepository.findById(userId)
                .orElseThrow(() -> new ApiException(NOT_FOUND));
                
            CouponIssue couponIssue = CouponIssue.create(coupon, user);
            couponIssue = couponIssueRepository.save(couponIssue);
            
            return CouponIssueResult.success(couponIssue);
            
        } catch (DataIntegrityViolationException e) {
            // 유니크 제약 위반 = 이미 발급받음
            // 수량은 증가했지만 발급 기록 생성 실패 시 롤백됨
            return CouponIssueResult.failed("이미 발급받은 쿠폰입니다.");
        }
    }
}
```

### 2.3 캐시 관리 (Redis 업데이트)
```java
@Component
@RequiredArgsConstructor
public class CouponCacheManager {
    private final RedisTemplate<String, String> redisTemplate;
    private final ObjectMapper objectMapper;
    
    public void markAsIssued(Long couponId, Long userId) {
        String issuedKey = "coupon:" + couponId + ":issued";
        redisTemplate.opsForSet().add(issuedKey, userId.toString());
        
        // TTL 설정 (메모리 관리)
        redisTemplate.expire(issuedKey, Duration.ofDays(1));
    }
    
    public void incrementIssuedCount(Long couponId) {
        String countKey = "coupon:" + couponId + ":count";
        redisTemplate.opsForValue().increment(countKey);
        redisTemplate.expire(countKey, Duration.ofDays(1));
    }
    
    public void updateUserStatus(Long userId, Long couponId, String status, Object data) {
        String statusKey = "user:" + userId + ":coupon:" + couponId + ":status";
        
        Map<String, Object> statusInfo = new HashMap<>();
        statusInfo.put("status", status);
        statusInfo.put("timestamp", System.currentTimeMillis());
        
        if (data instanceof CouponIssue couponIssue) {
            statusInfo.put("couponIssueId", couponIssue.getId());
            statusInfo.put("couponName", couponIssue.getCoupon().getName());
        } else if (data instanceof String message) {
            statusInfo.put("message", message);
        }
        
        try {
            String statusJson = objectMapper.writeValueAsString(statusInfo);
            redisTemplate.opsForValue().set(statusKey, statusJson, Duration.ofHours(1));
        } catch (JsonProcessingException e) {
            log.error("Failed to update user status", e);
        }
    }
}
```

### 3.3 동시성 검증 방법
```java
// 10,000명 동시 요청 테스트
ExecutorService executor = Executors.newFixedThreadPool(1000);
CountDownLatch latch = new CountDownLatch(10000);
AtomicInteger successCount = new AtomicInteger(0);
AtomicInteger failureCount = new AtomicInteger(0);

for (int i = 0; i < 10000; i++) {
    final int userId = i;
    executor.submit(() -> {
        try {
            String requestId = couponService.requestCoupon(userId, 1L);
            successCount.incrementAndGet();
        } catch (Exception e) {
            failureCount.incrementAndGet();
        } finally {
            latch.countDown();
        }
    });
}

latch.await();

// 결과 검증
log.info("성공: {}, 실패: {}", successCount.get(), failureCount.get());
// 정확히 100개만 발급되어야 함
```

## 4. 운영 방안

### 4.1 모니터링 지표

#### 비즈니스 메트릭
- **쿠폰 발급률**: 요청 대비 성공적 발급 비율
- **중복 발급 건수**: 시간당 중복 발급 시도 건수
- **평균 대기 시간**: 요청부터 결과 확인까지 시간

#### 시스템 메트릭
- **Kafka Consumer Lag**: 메시지 처리 지연 시간
- **Redis 응답 시간**: 캐시 조회 성능
- **DB Connection Pool**: 데이터베이스 연결 상태

### 4.3 장애 대응 방안

#### Redis 장애
- **영향**: 사전 검증 불가, 상태 조회 불가
- **대응**: DB 직접 조회로 fallback
- **복구**: Redis 재시작 후 캐시 warming

#### Kafka 장애
- **영향**: 비동기 처리 중단
- **대응**: 요청 접수는 계속, 처리는 지연
- **복구**: Kafka 복구 후 메시지 자동 처리

#### DB 장애
- **영향**: 전체 서비스 중단
- **대응**: Read Replica로 조회 기능 유지
- **복구**: 마스터 DB 복구 후 정상화

### 4.4 캐시 일관성 관리

@Component
@RequiredArgsConstructor
public class CacheConsistencyManager {
    
    @Scheduled(fixedRate = 300000) // 5분마다
    public void syncCacheWithDatabase() {
        List<Coupon> activeCoupons = couponRepository.findActiveCoupons();
        
        for (Coupon coupon : activeCoupons) {
            // DB와 Redis 수량 동기화
            String countKey = "coupon:" + coupon.getId() + ":count";
            redisTemplate.opsForValue().set(countKey, 
                coupon.getIssuedQuantity().toString(), 
                Duration.ofDays(1)
            );
        }
    }
    
    public void handleCacheFailure(Long couponId, Exception e) {
        log.warn("Cache operation failed for coupon: {}, falling back to DB", couponId, e);
        // Redis 실패 시 DB로 fallback
        return couponRepository.isIssuedMember(couponId, userId);
    }
}
